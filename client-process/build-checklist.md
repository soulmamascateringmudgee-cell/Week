# Country Smart AI — Website Build Checklist

The repeatable SOP. Duplicate this for every new website — as a Notion page, a Trello board, a copy of the Google Sheet, or just a copy of this file in the client's folder.

There's also a tickable version at [`checklist.html`](checklist.html) that saves your progress in the browser and prints cleanly.

## Stage 1 — Enquiry

- [ ] Enquiry received
- [ ] Package confirmed
- [ ] Scope confirmed
- [ ] Price approved
- [ ] Deposit invoice sent
- [ ] 50% deposit paid
- [ ] Intake form sent

> Nothing starts until the deposit is in. Sending the intake form is the reward for paying the deposit, not the thing that gets them to pay it.

---

## Stage 2 — Content collection

- [ ] Intake form completed
- [ ] Logo received
- [ ] Brand colours confirmed
- [ ] Photos received
- [ ] Services / menu received
- [ ] Contact details confirmed
- [ ] Social links collected
- [ ] Testimonials collected
- [ ] Domain details confirmed
- [ ] Missing information requested

> **Do not start building until this stage is mostly complete.** This one rule will save your sanity. Building around placeholder content means building twice.
>
> If you're waiting on something, send one clear chase listing everything outstanding, rather than a message each time you notice a gap.

---

---

## Stage 5 — SEO basics

- [ ] Page titles added
- [ ] Meta descriptions added
- [ ] Business name and location included naturally
- [ ] Image alt text added
- [ ] Heading structure checked
- [ ] Google Business Profile linked (if relevant)

> Call this **basic on-page SEO setup** in your package wording. Don't promise rankings, ongoing optimisation or advanced SEO at this price point — it sets an expectation you can't close out.

---

## Quality control — before the client sees it

Work through the whole list on a real phone, not just a resized browser window.

- [ ] Test every button
- [ ] Test contact form (submit it and confirm the email lands)
- [ ] Test phone links (tap on a phone, confirm it dials)
- [ ] Test email links
- [ ] Check spelling
- [ ] Check pricing
- [ ] Check addresses
- [ ] Check desktop
- [ ] Check mobile
- [ ] Check tablet
- [ ] Check loading speed
- [ ] Check social links (every one opens the right profile)
- [ ] Check navigation
- [ ] Remove placeholder text and images
- [ ] Favicon and logo appear correctly

- [ ] **Preview sent to client, with the revision form link**

---

## Revision round

- [ ] Preview link sent
- [ ] Revision form link sent with it
- [ ] Client given a clear review deadline
- [ ] All changes received through the form
- [ ] Changes worked through
- [ ] Updated preview sent
- [ ] Revision round closed

**The boundary, in your words:**

> Your package includes one revision round. Please review the entire website and send all requested changes together.

One place to submit changes. Not a text today, an email tomorrow and their neighbour's opinion on Sunday night. If extra changes come in after the round closes, they're quoted separately — say so kindly and early, not for the first time when it happens.

---

## Launch

- [ ] Revision completed
- [ ] Client approval received
- [ ] Final invoice sent
- [ ] Final payment received
- [ ] Domain connected
- [ ] Website published
- [ ] SSL active (padlock showing, http redirects to https)
- [ ] Contact form tested again on the live site
- [ ] Google Analytics added (if included)
- [ ] Google Search Console added (if included)
- [ ] Client sent login and handover information
- [ ] Client asked for a testimonial
- [ ] Portfolio screenshots saved
- [ ] Before / after case study created

> Test the contact form **again** after launch. Forms that worked on the preview URL are the single most common thing to break when the domain is connected.

---

## 7-day post-launch check

Diary it for one week after launch.

- [ ] Site is working
- [ ] Enquiry form tested
- [ ] Any minor launch issues fixed
- [ ] Review / testimonial requested

> A lovely client experience without promising endless support. It's a defined check-in with an end date, not an open door.
